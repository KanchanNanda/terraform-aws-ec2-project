---------------Terraform Interview Questions----------------------------

Question1  What is Infrastructure as Code?
Answer     Infrastructure as Code (IaC) is the process of managing infrastructure using code instead of manually    creating resources.

Question2  What is Terraform?
Answer     Terraform is an open-source Infrastructure as Code tool developed by HashiCorp.

Question3  What is terraform init?
Answer     It initializes the Terraform working directory and downloads providers.

Question3  What is terraform plan?
Answer     It shows what resources Terraform will create, modify, or destroy.

Question4  What is terraform apply?
Answer     It creates or updates the infrastructure.

Question5  What is terraform destroy?
Answer     It removes all resources managed by Terraform.

Question6  What is terraform.tfstate?
Answer     It stores the current state of infrastructure.
